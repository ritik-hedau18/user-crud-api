# User Profiles Directory API

User Profiles Directory API is a Spring Boot REST API service managing User records.

## Features
- Core CRUD routes
- Request field validators
- Local database storage

## Running Locally
Run `mvn spring-boot:run` in the project directory. The service runs on port `8080`.
